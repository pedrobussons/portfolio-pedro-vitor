# Portfólio Pessoal — Pedro Vitor

Portfólio pessoal desenvolvido como projeto acadêmico do curso de Engenharia de Software, com o objetivo de apresentar minha trajetória, formação, habilidades técnicas e experiências profissionais.

## Sobre o projeto

O projeto consiste em uma página web pessoal, desenvolvida utilizando HTML5 e CSS3, com layout responsivo e organização de conteúdo em diferentes seções.

A proposta é reunir informações acadêmicas e profissionais em um único ambiente, além de demonstrar conhecimentos iniciais em desenvolvimento Front-End.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **Flexbox e Grid:** organização dos elementos da página.

## Funcionalidades

- Apresentação pessoal.
- Seção sobre minha trajetória acadêmica e profissional.
- Exibição de habilidades técnicas.
- Informações de formação e experiência profissional.
- Área de contato e links profissionais.
- Layout adaptável a diferentes tamanhos de tela.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
